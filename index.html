A capture is a snapshot of your protein. Take one before a move and one after, and this page tells you in plain words what changed, where, and what you could try.

New here? It takes a few seconds and doesn’t need Foldit.

Before you start, you need

  • Foldit on a computer, with this page open on the same computer.
  • A puzzle that allows recipes. The Intro Puzzles don’t, so pick a Beginner or Science puzzle with 11 to 450 segments. Under 100 is quickest.
  • Chrome or Edge, so the page updates by itself. Other browsers work, with one extra click per capture.

Set up once, in four steps

  1. 1Download the capture recipe

    A recipe is a small script that Foldit can run. This one only measures your protein. It does not move it.

    You should get a file named foldit-energy-capture.lua, usually in your Downloads folder. There is no need to open it.

    See or copy what is inside
  2. 2Take your first capture in Foldit
    1. In Foldit, open your puzzle.
    2. Open the Cookbook, where recipes are kept.
    3. At the bottom of the Cookbook, click Load local recipe (the folder icon).
    4. Choose foldit-energy-capture.lua.
    5. A small box opens. Click Capture.
    6. Don’t move the protein until it finishes. Brief flickering bands are normal.

    You should see “Capture finished” in the recipe output (the Show recipe output icon, also at the bottom of the Cookbook).

  3. 3Connect this page to Foldit

    Foldit writes what a recipe prints into a file called the script log. You only have to show this page where that file is.

    1. Copy this usual location: C:\Foldit\scriptlog.default.xml
    2. Copy this usual folder: /Applications/Foldit.app/Contents/Resources
    3. Find the folder you start Foldit from.
    4. Click Choose the script log below.
    5. Click the file button below.
    6. Paste into the File name box and click Open.
    7. Press Cmd+Shift+G, paste, press Return, then pick scriptlog.default.xml or scriptlog..xml.
    8. Pick scriptlog.default.xml in that folder.
    9. If the browser asks for permission to view the file, allow it.

    This browser can’t update by itself. Choose the file again after every capture, because Foldit replaces it each time.

    You should see your puzzle’s name under Your puzzles, with one step.

    I can’t find the file
    • It only exists after a recipe has run, so finish step 2 first.
    • It is in the folder Foldit was installed in or started from. Search your computer for scriptlog.
    • If you use tracks, the track’s name replaces default in the file name.
    • You can skip the file: copy everything from Foldit’s recipe output and paste it here after each capture.
  4. 4Make one move and capture again
    1. In Foldit, make one move, for example Shake, Wiggle or a pull.
    2. Run the recipe again, the same way as in step 2.
    3. If you like, type what you did in the Move box. Then click Capture.
    4. Come back to this page.
    5. Come back here and choose the script log again (step 3).

    You should see a sentence such as “This move made the energy worse”, with the main reason under it.

From then on, repeat three things

  1. Move once in Foldit
  2. Capture with the recipe
  3. Read the reason here

Keep this page open while you play. Foldit keeps only the latest recipe run in its log, so a capture taken while the page is closed can be lost.

If something doesn’t work

I can’t find the Cookbook, or recipes are unavailable

You are probably in an Intro Puzzle, where there is no Cookbook. Open a Beginner or Science puzzle.

The recipe seems stuck

It prints its progress in the recipe output. Bigger proteins take longer. If you cancel, the temporary bands are removed; just run it again.

The page says there is no capture in the file

Either another recipe ran afterwards and replaced the log, or this is another track’s log. Run the capture recipe again, then look at the newest scriptlog file.

Nothing new appears after a capture

Look under the guide button for “Connected”. If it says access expired, press Reconnect. Without Chrome or Edge, choose the file again after every capture.

The analysis is slow

Expect about 4 seconds at 76 segments, 30 seconds at 150 and 5 minutes at 430. You can keep playing meanwhile.

A step says “failed”

Click that step to read the reason. A message about bond lengths or atom numbering is a fault in this tool: please report it, without attaching solutions of active puzzles.

Privacy. Your captures and history stay in this browser. Clearing site data erases them.

Fair play. Don’t pass captures or exports of active puzzles to other players. Follow the Foldit community rules.

What the numbers are. Amber ff14SB + GBn2 potential energies of static structures: not free energies and not Foldit’s Rosetta score. Proteins of 11–450 residues; ligands, nucleic acids and symmetry partners are not modelled.
