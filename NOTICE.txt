# Sources and licences

This is an unofficial tool. It is not affiliated with Foldit. It contains no Foldit code or assets
and does not read or decode Foldit's save files.

## Parameters

- **ff14SB**: J. A. Maier, C. Martinez, K. Kasavajhala, L. Wickstrom, K. E. Hauser, C. Simmerling,
  *J. Chem. Theory Comput.* 11, 3696-3713 (2015). Values taken from `amber14/protein.ff14SB.xml`
  as distributed with OpenMM, converted from AmberTools.
- **GBn2 (igb = 8)**: H. Nguyen, D. R. Roe, C. Simmerling, *J. Chem. Theory Comput.* 9, 2020-2034 (2013).
  Values and tables taken from OpenMM's `customgbforces.py`.
